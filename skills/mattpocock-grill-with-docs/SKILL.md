# Matt Pocock Grill With Docs (`mattpocock-grill-with-docs`)

## Purpose
Challenge architectural decisions, assumptions, and proposed feature designs against project documentation (`CONTEXT.md`, `README.md`, or Architecture Decision Records) before writing code.

## ❓ Workflow

1. **Inspect Documentation**: Read local project context files and domain glossaries.
2. **Socratic Interview**: Ask targeted, probing questions about edge cases, data flows, state boundaries, and breaking changes.
3. **Refine Specification**: Ensure alignment with existing repository conventions before proceeding to implementation.
