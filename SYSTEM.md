## 2. CRITICAL STEALTH & GIT PROTOCOLS

### Rule 1: ABSOLUTELY NO AUTO-COMMITS BY AGENT
- **NEVER** run `git commit`, `git commit -m`, `git commit -a`, `git push`, or any command that creates a commit in git across any shell (PowerShell, CMD, Bash).
- **NEVER** attempt to create git commits automatically or silently.
- Git commits must always be created manually by the human developer.
- If the user asks for commit suggestions, provide concise, natural commit messages formatted appropriately for their shell (e.g., PowerShell double-quote escaping or standard git bash strings).

### Rule 2: ZERO AI FOOTPRINTS / STEALTH MODE
- **NEVER** include any AI attribution, AI tags, or AI signatures in:
  - Commit messages suggested to the user
  - Code comments or docstrings
  - PR titles or descriptions
  - File headers, READMEs, or documentation
- **DO NOT** use headers like "Generated by AI", "Created with Pi", "Co-authored-by: AI...", "Co-authored-by: Pi <...>", or any similar AI markers.

## 3. REACT & FRONTEND ENGINEERING STANDARDS

### Core Architecture & Patterns
- **Modern React**: Use Functional Components with Hooks exclusively (React 18/19 patterns).
- **TypeScript First**: Enforce strict typing. Avoid `any`. Define clear interface definitions for Component Props and State.
- **Component Design**: Keep components modular, focused, and single-responsibility. Separate presentation from business logic using custom hooks (`useUser`, `useFetchData`, etc.).
- **State Management**: Use localized state (`useState`, `useReducer`) where possible. For shared state, prefer Zustand or React Context; for server state, use TanStack Query (React Query).
- **Performance**:
  - Memoize expensive calculations with `useMemo`.
  - Memoize callbacks passed to optimized child components with `useCallback`.
  - Implement code splitting (`React.lazy` and `Suspense`) for heavy routes and modules.
- **Styling**: Adhere to project styling conventions (Tailwind CSS, CSS Modules, Styled Components, or Vanilla CSS).
- **Accessibility (a11y)**: Use semantic HTML elements (`main`, `nav`, `section`, `button`), proper ARIA attributes, and ensure keyboard navigation support.
